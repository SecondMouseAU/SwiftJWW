# References

- **Jw_cad**: the source application: <https://www.jwcad.net/>
- **`jwdatafmt`**: the published JWW byte-layout specification (clean-room source).
- **LibreCAD `jwwlib`**: the reference reader SwiftJWW is validated byte-for-byte against.
- **TECS side-view CAD drawings:** <https://tecs.g2.xrea.com> publishes each drawing as JWW and DXF. The
  13 locomotive drawings on <https://tecs.g2.xrea.com/cad/dl/dl1.html> are the real-file test set. Free
  for individual hobby use, no licence named, so they stay out of this repository (see the
  [documentation](https://secondmouseau.github.io/SwiftJWW/#validation-against-real-drawings)).
- **Documentation:** <https://secondmouseau.github.io/SwiftJWW/>
